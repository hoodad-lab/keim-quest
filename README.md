# KEIM Quest

A KEIM Australia platform game starring the KEIM Koala. Play it in the browser.

Play: https://hoodad-lab.github.io/keim-quest/

Embed on keim.com.au (Wix: Add > Embed Code > Embed a site, or custom HTML):

```html
<iframe src="https://hoodad-lab.github.io/keim-quest/" width="100%" style="aspect-ratio:1280/780;border:0" allow="autoplay" title="KEIM Quest"></iframe>
```

Controls: arrows / A D to move, Space / W / Up to jump, X / J to throw a crystal (hold to run), Enter to start. Touch buttons appear on phones.
